# Image requirements

This folder currently uses original SVG illustrations so the site does not depend on random stock photos.

Replace with branded assets before a large ads launch.

## Required / recommended

| File | Use | Notes |
| --- | --- | --- |
| `logo.svg` | Navbar and schema logo | Keep square, high contrast |
| `favicon.svg` | Browser tab | Simple mark |
| `og-default.svg` | Open Graph fallback | 1200×630. Export PNG/WebP for better social previews |
| `products/*.svg` | Product cards | Replace with UI screenshots |
| `portfolio/*.svg` | Portfolio thumbnails | Replace with project captures |
| `case-studies/*.svg` | Case study art | Optional photography of work, not generic people stock |
| `blog/*.svg` | Article covers | Diagrams preferred |

## Guidelines

- Prefer WebP or AVIF for photography; keep SVG for diagrams and UI chrome
- Always set width, height and alt text
- Lazy-load below-the-fold images
- Do not use fake client logos
- Do not use invented dashboard metrics as if they were client results
